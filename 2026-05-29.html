Anthropic Engineering

Anthropic Engineering blog

Anthropic published a rare public postmortem on recent Claude Code quality complaints, tracing them to three separate client-side changes — not model degradation. The culprits: a March 4 switch from high to medium reasoning effort (reverted April 7), a March 26 bug that kept clearing old thinking every turn instead of just once after idle (fixed April 10), and an April 16 system prompt tweak to reduce verbosity that accidentally hurt coding quality (reverted April 20). The aggregate effect looked like broad, inconsistent degradation because each change hit different traffic slices on different schedules. The post is a useful window into how hard it is to distinguish real model regressions from prompt and client-layer changes — and a reminder that even top labs ship bugs that feel like 'the model got dumber.'

We take reports about degradation very seriously. We never intentionally degrade our models, and we were able to immediately confirm that our API and inference layer were unaffected.

Anthropic Engineering

Anthropic Engineering blog

This is the architectural deep-dive behind Managed Agents. Anthropic's engineering team explains how they virtualized an agent into three abstractions — session (append-only log), harness (the loop that calls Claude and routes tool calls), and sandbox (execution environment) — so each can be swapped without disturbing the others. The goal is to build a 'meta-harness' that outlasts any particular model version or implementation, much like OS abstractions (process, file) outlasted hardware generations. A concrete win: decoupling the 'brain' from the 'hands' (sandbox) cut p50 time-to-first-token by ~60% and p95 by over 90%, because sessions no longer pay container setup cost unless they actually need one. The post also candidly admits that harness assumptions go stale as models improve — context resets added for Sonnet 4.5's 'context anxiety' turned out to be dead weight on Opus 4.5.

We expect harnesses to continue evolving. So we built Managed Agents: a hosted service in the Claude Platform that runs long-horizon agents on your behalf through a small set of interfaces meant to outlast any particular implementation.
→ https://www.anthropic.com/engineering/managed-agents

Claude Blog

Claude Blog

Anthropic is shipping two enterprise-focused Managed Agents features: self-hosted sandboxes (public beta) and MCP tunnels (research preview). Self-hosted sandboxes let companies keep sensitive files and execution inside their own perimeter — or with managed providers like Cloudflare, Daytona, Modal, and Vercel — while Anthropic handles the orchestration layer. MCP tunnels allow agents to reach private MCP servers (internal databases, APIs, knowledge bases) without exposing them to the public internet, via a lightweight gateway that makes a single outbound connection. Named customers already building on the stack include Amplitude (Design Agent on Cloudflare), Clay (Sculptor GTM agent on Daytona), and Rogo (finance analyst agent on Vercel). It's a clear bid to make Claude palatable to security-conscious enterprises that won't let code or data leave their infrastructure.

Starting today, Claude Managed Agents can operate in a sandbox you control and connect to your private Model Context Protocol (MCP) servers.

Dan Shipper

Every co-founder and writer

The Takeaway: More AI automation paradoxically creates more demand for human experts, not less. Dan Shipper, co-founder of the AI-native media company Every, makes a contrarian case against the doom narrative sweeping the industry. Every has grown from 4 to 30 people since GPT-3 while becoming 'as agent-native as it gets' — yet Shipper insists the work has only multiplied. His core argument: AI makes 'yesterday's expert competence cheap,' which floods the zone with okay-but-not-quite-right output. That glut devalues generic work and simultaneously increases demand for experts who can shepherd it across the finish line or build systems to filter it. He points to Every's own Kieran building an entire inbox end-to-end in a month — something 'totally impossible' before — as proof that the floor rising lets experts reach higher. Shipper also pushes back on the idea that benchmarks mean human obsolescence. He notes that once a benchmark is saturated, it's trivial to 'unsaturate' it with a broader framing — and that anything humans can articulate as a difference, models will eventually hill-climb toward. The real gap, he argues, is that humans have wants, needs, and playful curiosity that aren't in the training data. Agents are built to be compliant, not self-motivated. 'The further away an agent gets from a human, the less valuable it is.'

If you just ride the models, you're going to be fine. If you care about leading a really ambitious life, I truly think that this is going to make that more possible for more people.
