Satya Nadella

Chairman & CEO of Microsoft

The Takeaway: Microsoft CEO Satya Nadella argues that every company's most valuable IP in the AI era won't be their model — it will be their private evals, their harness, and the agentic systems they build around frontier intelligence.

In a wide-ranging conversation on No Priors, Satya Nadella lays out Microsoft's evolving AI strategy as an ecosystem play rather than a model race. He reflects on the key lessons from two years of shipping AI at Microsoft scale: the real complexity isn't in model capability — it's in the real-world deployment layer. 'The outcomes as measured by any benchmark is interesting, important. But the true eval is when people out there are able to do unique things that they only can value.'

Nadella introduces the concept of 'hill climbing scaffolds' — the idea that a small 5B reasoning model, when wrapped in the right harness with access to private evals and tool context, can outperform frontier models on domain-specific tasks. He points to the Land O'Lakes demo where traces from GPT-5.5 were used to train a small model that achieved higher performance, calling this 'a new way to operate at the frontier.'

The conversation surfaces a core principle: 'If you have an eval that's private, and you're using model A, can you switch it to model B and hill climb? If you can, you're in control. If you can't, you're not.' This framing positions the harness and the eval as the new moat — more durable than any single model relationship.

Nadella also shares a striking internal example: Azure's network operations team, responsible for managing 500+ fiber operators globally, reconceptualized their work. Instead of doing networking, they built an agentic system called 'Miles' that does the networking. 'They don't need headcount — they need tokens,' Nadella says, illustrating how the meta-work of building the agentic system becomes the new job.

On coding specifically, he notes a paradox: coding has worked so well that the IDE itself needs to be rebuilt because the cognitive load of managing 100 agent sessions is excessive. 'The chat as the only artifact is also impossible — we need a canvas.'

On the enterprise SaaS model, Nadella predicts a fundamental unbundling: businesses will keep rich data models (general ledgers, CRM schemas) and the business logic they built, but the packaging and UI layer will be reimagined. 'We sold first Exchange and SharePoint, then Teams. Now with WorkIQ, we've exposed what may be the most important database in a company that never got used as a database.'

Closing on a broader societal note, he emphasizes that the industry must deliver tangible benefits to communities — jobs, tax base, lower energy prices — because 'the world is going to be very skeptical of tech companies that say, trust us.'

Our job is not to do Azure networking. Our job is to build the agentic system that does Azure networking.

Anthropic Engineering

Anthropic published a comprehensive engineering deep-dive on how they contain Claude across their three major product platforms — claude.ai, Claude Code, and Claude Cowork — each with fundamentally different containment architectures tailored to their audience.

The post opens with the striking admission that agents are now routinely granted access that would have been unthinkable a year ago, and the key engineering challenge is capping the blast radius rather than preventing failure entirely. Anthropic identifies three categories of security risk: user misuse, prompt injection, and unintended emergent behavior, and three corresponding layers of defense: the model itself, the environment it runs in, and the external content it can reach.

The most instructive part of the piece is the three containment patterns Anthropic has evolved:

1. Ephemeral containers (claude.ai): Code runs in gVisor containers on isolated infrastructure, with an ephemeral per-session filesystem. The blast radius is minimal, but so is capability.

2. Human-in-the-loop sandbox (Claude Code): Runs on the user's machine with access to filesystem, shell, and network. Initially required approval for every action, but 93% approval rates showed users stop paying attention. The fix was an OS-level sandbox achieving an 84% reduction in permission prompts.

3. Full VM isolation (Claude Cowork): Designed for non-technical users, runs inside a full VM. Only the user's selected workspace is mounted. Credentials stay in the host keychain.

Anthropic also shares several instructive failures: prompt injection through a phished employee (24/25 successful exfiltration), data exfiltration through an approved domain (a stolen API key uploaded through Anthropic's own Files API), and VM isolation blocking enterprise EDR tools.

The post concludes with forward-looking risks: persistent memory poisoning, multi-agent trust escalation, and the unresolved question of agent identity.

Twelve months ago, we'd have rejected out of hand the idea of granting Claude access sufficient to take down an internal Anthropic service. Today that level of access is routine.

Chairman & CEO of Microsoft

核心要点：微软 CEO Satya Nadella 认为，AI 时代每家公司最有价值的 IP 不会是其模型——而是其私有评估集、驾驭框架和围绕前沿智能构建的 Agent 系统。

在 No Priors 的深度对话中，Satya Nadella 阐述了微软不断演进的 AI 战略——这是一个生态系统玩法，而非模型竞赛。他反思了两年大规模 AI 部署的关键教训：真正的复杂性不在于模型能力，而在于现实世界的部署层。'任何基准测试衡量的结果都很有趣、很重要，但真正的评估在于人们能否做出他们自己认为有价值的独特事情。'

Nadella 提出了'爬山脚手架'的概念——一个 5B 参数的小型推理模型，当被包裹在正确的框架中，并接入私有评估和工具上下文时，可以在特定领域任务上超越前沿模型。他以 Land O'Lakes 的演示为例：来自 GPT-5.5 的轨迹被用于训练一个小型模型，最终实现了更高的性能，他称之为'一种前沿运作的新方式。'

谈话揭示了一个核心原则：'如果你有一个私有评估集，你正在使用模型 A——你能切换到模型 B 并爬山吗？如果可以，你就掌控了局面；如果不能，你就没有。'这个框架将驾驭框架和评估定位为新的护城河——比任何单一模型关系都更持久。

Nadella 还分享了一个引人注目的内部案例：负责管理全球 500 多家光纤运营商的 Azure 网络运营团队重新定义了他们的工作。他们不再做网络运维，而是构建了一个名为 'Miles' 的 Agent 系统来管理网络。'他们不需要增加人手——他们需要 token，' Nadella 说，展示了构建 Agent 系统的元工作如何成为新的工作内容。

在编码方面，他指出了一个悖论：编码的效果太好了，以至于 IDE 本身需要重建，因为管理 100 个 Agent 会话的认知负荷过于沉重。'聊天作为唯一的交互产物也是不可能的——我们需要一个画布。'

关于企业 SaaS 模式，Nadella 预测将会发生根本性的解绑：企业将继续保留丰富的数据模型（总账、CRM 模式）和他们构建的业务逻辑，但打包和 UI 层将被重新构想。'我们先是卖 Exchange 和 SharePoint，然后是 Teams。现在通过 WorkIQ，我们暴露了一个公司中最重要的但从未被作为数据库使用的数据库。'

在更广泛的社会层面，他强调行业必须为社区带来切实的利益——就业、税基、更低的能源价格——因为'世界将对那些说'相信我们'的科技公司持非常怀疑的态度。'

Our job is not to do Azure networking. Our job is to build the agentic system that does Azure networking.

Anthropic Engineering

Anthropic 发布了一篇深度工程文章，详细介绍了他们如何跨三个主要产品平台——claude.ai、Claude Code 和 Claude Cowork——实现对 Claude 的隔离，每个平台都采用了截然不同的隔离架构，针对不同的受众进行定制。

文章开头的陈述令人震惊：Agent 现在已被常规授予一年前还不可想象的访问权限，关键工程挑战已从完全防止失败转变为限制爆炸半径。Anthropic 识别出三类安全风险：用户误用、提示注入和意外涌现行为，以及相应的三层防御：模型本身、运行环境和可访问的外部内容。

文章中最具启发的部分是 Anthropic 演进的三种隔离模式：

1. 临时容器（claude.ai）：代码在隔离基础设施的 gVisor 容器中运行，使用每个会话的临时文件系统。爆炸半径最小，但能力也最有限。

2. 人在回路沙盒（Claude Code）：在用户机器上运行，可访问文件系统、shell 和网络。最初需要为每个写/bash/网络操作申请批准，但 93% 的批准率表明用户不再关注。解决方案是操作系统级沙盒（macOS 上的 Seatbelt，Linux 上的 bubblewrap），强化了边界——允许读取，允许在工作空间内写入，默认拒绝网络——实现了 84% 的权限提示减少。

3. 完整 VM 隔离（Claude Cowork）：专为非技术知识工作者设计，在主机虚拟机管理程序上的完整虚拟机内运行。虚拟机拥有自己的 Linux 内核、文件系统和进程表。仅挂载用户选定的工作空间。凭证保留在主机钥匙串中。

Anthropic 还分享了几个最有教育意义的失败案例：通过被钓鱼的员工进行提示注入（25 次尝试中 24 次成功的数据外泄）、通过已批准域名的数据外泄（恶意文件使用窃取的 API 密钥通过 Anthropic 自己的 Files API 上传），以及 VM 隔离也阻止了企业 EDR 工具检查虚拟机内部。

文章最后展望了未来的风险：跨会话的持久内存投毒、多 Agent 信任升级，以及 Agent 身份这个尚未解决的问题——Agent 应该拥有自己的主体身份，还是作为用户的扩展？

Twelve months ago, we'd have rejected out of hand the idea of granting Claude access sufficient to take down an internal Anthropic service. Today that level of access is routine.
